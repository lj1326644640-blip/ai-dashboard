# LLM 评审规则 — 思加图小红书爆款笔记（xhs-stacato）

对小红书三池（品牌/竞品/品类）笔记做人工级评审。输入 `data/xhs-stacato/<日期>/full.json`，
输出写 `data/xhs-stacato/<日期>/llm_scores/`。与海外AI日报的 rubric（docs/llm_rubric.md）**互不通用**。

## 输入字段
每条笔记：`id`、`pool`（brand=思加图品牌池 / competitor=竞品池 / category=品类池）、
`keyword`（命中的搜索词）、`title`、`text`（正文前400字）、`engagement`（likes/collects/comments/shares）、
`author`、`note_type`（图文/视频）、`tags`。规则分（CES合成：赞1+藏2+评4+转4）已算好，仅供参考。

## 输出格式（严格遵守）
```json
[
  {
    "id": "xhs_6a9c19cb...",
    "brand_rel": "思加图官方|思加图UGC|竞品|无品牌",
    "note_type": "种草|测评|攻略合集|避坑|穿搭教程|新品速递|日常分享|疑似广告水军",
    "ai_relevance": 8,
    "value": 7,
    "deconstruct": 8,
    "why": "一句话中文25-60字，写具体事实"
  }
]
```

## 字段定义

- **brand_rel**（品牌关联，枚举）：
  - 思加图官方：品牌/门店官方账号发布
  - 思加图UGC：素人或博主发布的思加图真实内容（种草/吐槽都算，含"杨幂同款"等代言联想）
  - 竞品：内容主体是竞品品牌（他她/百丽/真美诗/73hours/接吻猫/哈森/千百度/迪芙斯）
  - 无品牌：纯品类穿搭内容

- **note_type**（笔记类型，枚举单选）：种草 / 测评 / 攻略合集 / 避坑 / 穿搭教程 / 新品速递 / 日常分享 / 疑似广告水军
  （明显是投放软文、模板化带货、标签堆砌的标"疑似广告水军"）

- **ai_relevance**（0-10，与"女鞋品类"的相关度；管线用这个字段名）：9-10 核心鞋履内容；6-8 明显相关（鞋是主角之一）；3-5 沾边（穿搭内容里带过）；0-2 无关噪音（关键词误命中）

- **value**（0-10，内容价值/热度质量）：真实上脚反馈、尖锐对比、详细避坑=高分；滤镜种草、无信息量、引流水=低分。
  互动高不代表价值高——**价值独立于互动打分**。

- **deconstruct**（0-10，可拆解仿写价值，本系统独有）：这条笔记的**爆款手法**是否值得品牌内容团队学习。
  高分：标题有可复用公式（数字/冲突/身份代入）、封面钩子明确、结构清晰（痛点→方案→证明）、情绪共鸣强、评论区互动设计。
  低分：爆点靠脸/靠运气/无法复制。
  这是给"搜集样本做拆解仿写"用的核心字段，请基于标题+正文实际手法判断。

- **why**：25-60字中文，写具体事实（爆了什么、手法是什么），不写空话。

## 操作要求
1. 每批15-25条，逐条打分不批量同分
2. **brand池（pool=brand）优先仔细评**——这是品牌自己的声量资产
3. 疑似广告水军必须标出（品牌方需要区分真实口碑 vs 投放）
4. 不确定就保守，0-2分在why注明"疑似噪音"
