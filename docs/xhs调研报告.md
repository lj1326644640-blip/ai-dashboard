# 小红书品类热度抓取 — 调研报告

> 调研日期：2026-10-05。四路并行：平台机制 / 本机可达性实测 / Apify与第三方API / 开源自建方案。
> 结论先行：**技术上可行，但没有官方渠道，只能走"逆向网页接口"生态；推荐用付费API（TikHub）做试点，Apify做备份，自建MediaCrawler做长期低成本选项。打分规则需要独立于海外AI热点全新设计。**

## 一、本机实测结论（最硬的事实）

| 测试项 | 结果 |
|---|---|
| 主站直连 | ✅ 302→/explore，国内直连完全可用，**无需代理** |
| 未登录访问发现页/搜索页 | 302 踢到登录墙；搜索页只返回 SPA 空壳（`noteIds:[]`，纯客户端渲染）|
| 直打搜索API（edith.xiaohongshu.com）| POST 返回业务码 `-101 "无登录信息"`；**不会封IP**（正常JSON报错）|
| robots.txt | 对全部搜索引擎 Disallow /（仅放行首页、sitemap），官方态度明确 |
| 数据双门槛 | **登录Cookie + x-s/x-t/x-s-common 签名**，缺一不可 |

## 二、平台机制（打分规则的依据）

1. **CES互动公式**（从业共识，2017至今，非官方）：`赞×1 + 藏×1 + 评×4 + 转×4 + 关注×8`
   —— **深度互动（评论/转发/关注）权重是赞藏的4-8倍**，和海外平台"点赞为王"完全不同
2. **流量双引擎**：推荐流约50% + 搜索约20-65%（官方称70%用户先搜答案）→ 同一篇笔记有**两个热度**（推荐热度/搜索热度），理想情况分开建模
3. **生命周期**：推荐爆发期 3-7 天（爆文可延至1个月）+ **搜索长尾 6-12 个月** → 抓取窗口不能套用海外的72小时，建议**7天首评 / 14-30天复评确认爆款 / 长尾跟踪**三段式
4. **爆文行业经验值**：赞藏评总数>1000；互动率>5%；**收藏占比高=攻略/教程型**（品类热度的重要信号）
5. **品类频道接口存在**：发现页有 `homefeed.fashion_v3 / food_v3 / cosmetics_v3` 等品类流（MediaCrawler 源码核实），搜索自带 最热/最新 排序——对"品类热度"场景是现成的入口
6. **官方渠道零开放**：开放平台只做电商订单物流；灵犀只有品牌级洞察无逐条笔记API；蒲公英/聚光只看自己 → 这就是千瓜/新红/灰豚全是**SaaS看板无REST API**的根本原因

## 四、打分系统设计含义（与海外AI热点的四点本质差异）

| 维度 | 海外AI热点（现网） | 小红书（需新建） |
|---|---|---|
| 互动合成 | 赞+2×转+评+引用 | **CES思路：评×4+转×4+关注×8 > 赞/藏**；收藏占比单独建模（攻略型信号）|
| 时间窗 | 72小时 | **三段式：7天首评 / 30天复评 / 搜索长尾周跟踪** |
| 热度结构 | 单一时间线热度 | 推荐+搜索双热度 |
| LLM评审规则 | 英文内容、AI相关度+价值 | 中文笔记规则：种草/攻略/测评/避坑/合集类型学、标题党识别、评论区质量 |

## 七、Phase A 试点实测结果（2026-10-06，思加图项目启动）

**zen-studio/rednote-search-scraper 实测通过**（免费试用）：
- 入参：`{"keywords": ["思加图"], "maxItems": 20}` → 返回 **97条**（maxItems 未严格生效，单关键词全量返回）
- **字段完整度 97/97**：赞/藏/评/转（engagement对象）、timestamp、author（含nickname/userid）、url（含xsec_token可查详情）、tag_info、type（图文/视频）
- 数据真实性：近30天50条、近7天21条、**官方/门店账号32条**（如"郑东万象城思加图"）；互动分布真实（赞0-1810、藏max1328、评max487）
- Top样例（CES=赞+2藏+4评+4转）：①"商场女鞋纯个人购物感受，思加图好但…"（5458，高收藏真实测评）②"20年前的思加图，绝了"（3833，怀旧情绪爆文487评）③"备婚日记｜思加图Burano蕾丝岛二选一"（3572）
- 注意：maxItems 不严格生效 → 单词量大时计费可控性差，**量产用 TikHub（可翻页精确控制），zen-studio 作备份/抽样**

**socialdatax 未跑通**：schema 确认（operation=search_notes/keyword/max_items），但运行时始终报 "max-items-must-be-greater-than-zero"（免费计划拦截，需人工核其计费配置）——列为备选不阻塞。

**通道结论：试点管线用 zen-studio（已验证）；正式量产待 TikHub（用户注册后接入，$0.01/请求可精确翻页）。**

## 五、推荐试点方案（低成本三步）

1. **Step 1 数据样例对比（1小时，近零成本）**：
   - TikHub 注册（送$0.05）搜"AI工具"抓30条 → 看字段完整度
   - 现有Apify账号跑 zen-studio 3次免费试用 + socialdatax 5次免费 → 同关键词对比
2. **Step 2 打分规则草稿**：CES合成公式 + 三段式窗口 + 中文笔记LLM rubric 草案（拿到真实数据后定稿）
3. **Step 3 决策**：数据质量 OK → 正式通道选 TikHub（便宜）或 Apify（托管省事）；要零成本走量 → MediaCrawler 自建（独立小号+CDP+低频+接受维护）
4. **工程兜底**：fetcher 接口做成多供应商抽象，一家失效切另一家（小红书接口生态变动是常态）

## 六、风险声明

- 所有路线均为非官方接口，需自行遵守小红书ToS；自建路线 README 自身禁止商用
- 自建路线存在账号封禁风险（2025-2026风控显著升级），**绝对不要用大号/运营号**
